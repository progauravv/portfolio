# Gaurav Gautam - Portfolio Website

A modern, responsive portfolio website for Gaurav Gautam with a futuristic cyberpunk design theme.

## Features

### 🎨 Design & UI
- **Glassmorphism Effects**: Blurred transparent cards with modern aesthetics
- **Cyberpunk Theme**: Neon glow accents (blue, purple, green)
- **Smooth Gradients**: Dynamic background animations
- **Custom Cursor**: Interactive cursor with glow effects (desktop only)

### 📱 Responsive Design
- **Mobile-First Approach**: Optimized for all screen sizes
- **Breakpoints**: 
  - Mobile: < 768px (stacked layout, hamburger menu)
  - Tablet: 768px - 1024px (2-column layout)
  - Desktop: > 1024px (multi-column grid)
- **Touch-Friendly**: Optimized buttons and spacing for mobile devices

### ⚡ Performance & Animations
- **Smooth Scrolling**: JavaScript-powered navigation
- **Scroll Reveal Animations**: Intersection Observer API
- **Typing Animation**: Dynamic text in hero section
- **Progress Bars**: Animated skill indicators
- **Parallax Effects**: Hero background movement

### 🏗️ Structure
- **Hero Section**: Animated intro with CTA buttons
- **About Section**: Profile with statistics
- **Skills Section**: Interactive skill cards with progress
- **Projects Section**: Portfolio showcase with tech tags
- **Education Timeline**: Vertical timeline with animations
- **Contact Section**: Form validation and social links

### 🛠️ Technical Implementation
- **HTML5**: Semantic markup structure
- **CSS3**: Flexbox, Grid, custom properties, media queries
- **Vanilla JavaScript**: No frameworks required
- **Optimized**: Clean, maintainable code

## Files

- `index.html` - Main HTML structure
- `style.css` - Complete styling with responsive design
- `script.js` - Interactive features and animations

## Getting Started

1. **Open in Browser**: Simply open `index.html` in any modern web browser
2. **Local Server** (optional): For best results, use a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   
   # Using PHP
   php -S localhost:8000
   ```

## Customization

### Colors
Edit CSS variables in `:root`:
```css
--primary-color: #00d4ff;
--secondary-color: #ff00ff;
--accent-color: #00ff88;
```

### Content
Update text content directly in HTML:
- Name and tagline in hero section
- About text and stats
- Skills and projects
- Contact information

### Animations
Adjust timing and effects in `script.js`:
- Typing speed
- Scroll reveal thresholds
- Animation durations
