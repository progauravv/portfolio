# Gaurav Gautam - Static Portfolio Website

This folder contains the complete, pure static version of Gaurav Gautam's portfolio website built with only:
- Plain **HTML5** (`index.html`)
- Plain **CSS3** (`style.css` + Tailwind CDN / modern CSS)
- Plain **JavaScript (ES6+)** (`script.js`)

## Features
- **Zero Build Tools Required**: Open `index.html` directly in any web browser (Chrome, Edge, Firefox, Safari) or upload it to any web host (GitHub Pages, Netlify, Vercel, cPanel, Cloudflare Pages, Firebase Hosting, Apache, NGINX).
- **Identical Visual Design**: Retains the exact cosmic ambient background, glassmorphism cards, glowing borders, typography, and responsive layouts.
- **Identical Interactive Functionality**:
  - Smooth scroll navigation
  - Dynamic Island navigation pill with scrolled glassmorphism state
  - Active section scroll spy (Home, About, Skills, Project, Contact)
  - Mobile hamburger drawer menu
  - Interactive project detail modal dialogs with full architectural highlights
  - 1-click clipboard copy for email with instant feedback
  - Contact form with validation and Formspree delivery / mailto fallback
  - Minimalist footer with devotional quote: "हर हर महादेव ❤️"
